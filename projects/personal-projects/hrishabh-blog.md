## 📝 Detailed Description

A modern, content-first blogging platform built by Hrishabh Gupta to publish tutorials, deep dives on distributed systems, AI engineering, and personal essays:

- **Bilingual Publishing:** Dual-language layout with seamless toggling between Hindi and English articles.
- **Markdown & MDX Rendering:** High-speed syntax highlighting for code snippets, LaTeX mathematical notation, and interactive callouts.
- **SEO & Social Sharing:** Automatic OpenGraph preview card generation and dynamic sitemap generation for search discovery.
