## 📝 Detailed Description

Kautilyam is a next-generation cyber defense portal coupled with **Zylar**, a multi-agent autonomous Security Operations Center (SOC) system:

- **Autonomous Threat Mitigation:** Uses deterministic LangGraph orchestration to coordinate defensive agents against network intrusions and anomaly spikes.
- **Threat Correlation:** Built with NetworkX graph algorithms to correlate multi-vector attack paths across complex distributed topologies.
- **Machine Learning Anomaly Detection:** Scikit-Learn models trained on telemetry logs to isolate zero-day indicators of compromise.
- **Local Threat Intelligence:** Connects to local LLMs via Ollama for privacy-first security log interpretation and mitigation playbooks.
